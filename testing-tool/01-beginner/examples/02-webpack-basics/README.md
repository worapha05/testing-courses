# 02 — Webpack Basics

ตัวอย่าง config Webpack สำหรับแอปเล็ก ๆ พร้อม SCSS และ environment variables

```bash
# จาก root ของ bootcamp (หลัง npm install)
npm run build:webpack
```

ไฟล์สำคัญ:

- `webpack.config.cjs` — entry, loaders, plugins, Dotenv
- `src/index.js` — entry
- `src/styles.scss` — preprocessor
- `.env.example` — ตัวแปรตัวอย่าง
