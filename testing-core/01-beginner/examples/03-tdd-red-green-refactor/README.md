# TDD Kata — Password Policy (Red → Green → Refactor)

ตัวอย่างนี้จำลองวัฏจักร TDD สำหรับกฎรหัสผ่าน

## ขั้นที่ 1 — RED

เขียนเทสก่อน โดยยังไม่มี implementation ที่ถูกต้อง:

- ความยาวอย่างน้อย 8
- ต้องมีตัวเลขอย่างน้อย 1 ตัว
- ต้องมีตัวพิมพ์ใหญ่และพิมพ์เล็ก

รันแล้วต้องแดง

## ขั้นที่ 2 — GREEN

เขียนโค้ดน้อยที่สุดใน `passwordPolicy.js` ให้ผ่าน

## ขั้นที่ 3 — REFACTOR

ดึง validation เป็นรายการกฎที่อ่านง่าย เพิ่มข้อความ error ที่เป็นมิตร โดยเทสเดิมยังเขียว

ดูโค้ดสุดท้ายหลัง refactor ในไฟล์ปัจจุบัน แล้วลองลบ implementation แล้วทำใหม่ด้วยตัวเอง
